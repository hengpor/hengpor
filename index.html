GrocerySmart

For busy families who hate overpaying at the grocery store. A batch pipeline pulls weekly flyer deals from Canadian stores into Supabase, the app fetches and surfaces the best of them, and AI builds a customizable meal plan around what's on sale — so you eat well and spend less.

Framework Same Expo · React Native · TypeScript foundation as MoneyApp
Deals pipeline Python batch script scrapes weekly flyer deals and writes them into Supabase
AI Claude API builds a family meal plan from the current deals plus user customization
